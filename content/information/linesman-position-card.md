The 2026 NFHS Football Game Officials Manual renamed this position. The Head
Linesman is now the **Head Line Judge**, and this page moved with the name.

**[Head Line Judge Position Card](/information/head-line-judge-position-card/)**

Nothing about the job changed — you still work the sideline opposite the press
box and you still run the chains. Only the title did.

# Asked-questions ledger

Every question ever used in a quiz in this folder has exactly one row here.
**A citation key that appears in this table may not be used again.**

`Key` is the primary source anchor for the question: a case-book play number
(`8.5.2 SIT F`) or a rules-book citation (`7-2-5b EXC 1`). Match on the play or
article, ignoring the sub-letter — `8.5.2 SIT F(b)` and `8.5.2 SIT F(a)` are the
same key and the same question.

`Concept` is the trap being tested. Two questions with different keys but the
same concept are still duplicates — check this column too.
